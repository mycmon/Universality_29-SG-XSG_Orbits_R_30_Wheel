Résultat clé — pourquoi N≡4 est le plus asymétrique

N≡4 est le seul N mod 30 où :
1. Deux types purs coexistent (A et C) sans type mixte (B)
2. Les deux types appartiennent à des orbites différentes (sg vs xsg)
3. Le rapport A/C = 2 est une prédiction géométrique pure (2 tunnels vs 1)
4. Le tunnel C est symétrique (17,17) — p = q possible — unique parmi tous les tunnels de N≡4

C'est l'intersection minimale entre l'orbite sg-sg et l'orbite xsg-xsg dans (ℤ/30ℤ)★.
