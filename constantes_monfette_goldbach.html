Résultat central

r(N) ~ c · n_tunnels(N mod 30) · N / ln²(N)

c ≈ 0.47 — constante universelle de Monfette
n_tunnels ∈ {3, 4, 6, 8} — déterminé par N mod 30 (prouvé)
n_tunnels ≥ 3 pour toute classe paire sans exception

Comparaison : Hardy-Littlewood donne r(N) ~ 2·C₂·N/ln²N avec 2·C₂ = 1.320
Ici : k_min = 0.874  |  k_max = 3.408  |  k_moy ≈ 1.65
Rapport k_moy / (2·C₂) ≈ 1.25 — cohérent, légèrement supérieur à H-L global

Lien direct avec Goldbach

r(N) ≥ 1 observé sans exception sur [30, 150 000] pour les 15 classes.
N=12 est le seul apparent zéro — artefact de la restriction p≥7 (12 = 5+7 ✓).
La structure vers une preuve :
1. n_tunnels(N mod 30) ≥ 3 pour tout N pair → prouvé algébriquement
2. r(N) ~ c · n_tunnels · N/ln²N → mesuré empiriquement, c ≈ 0.47
3. Si c > 0 est prouvable → r(N) → ∞ → Goldbach vrai pour N assez grand

La constante c est la somme des constantes de Hardy-Littlewood stratifiées par tunnel (rp, rq), puis normalisée par n_tunnels.
C'est l'approche de Chen (1973) appliquée tunnel par tunnel.
Ce qui reste à faire analytiquement :
Calculer explicitement c = (1/n_tun) · Σ_{(rp,rq) actifs} C₂(rp,rq)
où C₂(rp,rq) est la constante de Hardy-Littlewood pour le tunnel (rp,rq).
Si cette somme est strictement positive — ce que les données confirment —
on obtient une borne inférieure r(N) ≥ ε·N/ln²N pour tout N pair ≥ 30.
